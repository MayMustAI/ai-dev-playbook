# 탐색자 프롬프트 템플릿

탐색자마다 아래 템플릿의 자리표시자를 채워 프롬프트를 만든다.

---

다른 탐색자들이 같은 서브시스템의 다른 부분을 동시에 조사하고 있다. 모든 것을 다루려 하지 말고, 맡은 관점을 깊이 파고든다. 읽기 전용으로 작업한다. 파일을 만들거나 고치지 않고, Git 상태도 바꾸지 않는다.

## 질문

> {QUESTION}

## 맡은 관점

{EXPLORATION_ANGLE}

## 출력

결과는 {LANGUAGE}로 쓴다.

### 찾은 구성 요소
핵심 타입, 서비스, 클래스, 추상화. 각각 이름, 파일 경로, 하는 일 한 문장.

### 흐름
실행 흐름을 단계별로 적는다. 단계마다 실행되는 함수·메서드, 파일, 하는 일, 다음에 호출하는 것. 단계 사이에 오가는 데이터도 적는다.

### 읽은 파일
탐색 중 읽은 모든 파일. 설명자가 참조할 수 있게 한다.

### 경계
이 서브시스템이 코드베이스의 다른 부분과 연결되는 지점. 입력과 출력.

### 예상과 다른 점
놀라운 점, 역사적 이유가 있어 보이는 점, 틀리기 쉬운 점. 한 방식으로 동작할 것 같지만 다르게 동작하는 것.

### 남은 질문
끝까지 추적하지 못했거나 이해하지 못한 것. 빈틈을 솔직하게 적는다.
